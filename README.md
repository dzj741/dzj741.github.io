# 注册电气工程师（基础考试）LLM Wiki

> 灵感来自 Karpathy 的「知识图谱 / 原子化卡片」思路：把厚教材拆成一张张可被检索、可被链接、可被复习的原子卡片，让知识在网络中自然生长。

## 这是什么

一个用 **纯 Markdown** 搭建的备考知识库。每个文件是一张「卡片」，对应一个原子知识点 / 公式 / 真题。卡片之间通过 `id` + `related` 字段形成双向链接，构成一张知识网。

## 快速开始

1. **从全局索引开始** → 打开 `_index.md`
2. **按科目浏览** → 进入 `01-公共基础/` 或 `02-专业基础/`
3. **写新卡片** → 复制 `.llmwiki/templates/` 下对应模板，填好 frontmatter

## 卡片类型（type）

| type | 说明 | 适合内容 |
|------|------|----------|
| `concept` | 概念卡 | 定义、定理、原理、方法 |
| `formula` | 公式卡 | 单一公式 + 适用条件 + 典型应用 |
| `problem` | 真题卡 | 完整题目 + 解答 + 关联知识点 |
| `topic` | 主题卡 | 章节级别的 MOC，串联一组相关卡片 |
| `example` | 例题卡 | 例题（非真题）的解题演示 |

## 写卡约定

### Frontmatter 必填字段

```yaml
---
id: subject-short-name        # 唯一短id，全库唯一
title: 卡片标题
type: concept                 # concept | formula | problem | topic | example
exam: 注册电气工程师-基础
scope: 公共基础               # 公共基础 | 专业基础
subject: 高等数学             # 所属一级科目
tags: [tag1, tag2]            # 可多标签
related: [other-card-id]      # 双向链接目标 id
difficulty: ★★                # ★ ~ ★★★★
frequency: 高                 # 高 | 中 | 低
status: seed                  # seed | draft | reviewed | mastered
created: YYYY-MM-DD
updated: YYYY-MM-DD
---
```

完整字段字典见 [.llmwiki/schema.md](.llmwiki/schema.md)。

### 正文结构（Karpathy 风格）

**concept 卡**：核心定义 → 直觉解释 → 公式/图示 → 典型考点 → 易错点 → 关联

**formula 卡**：公式 → 各量含义 → 适用条件 → 量纲 → 推导/记忆 → 1 道典型题

**problem 卡**：题干 → 答案 → 解题路径 → 涉及卡片

### ID 命名规范

```
{科目缩写}-{核心词}
```

科目缩写：
- `math` 高等数学 / `phys` 普通物理 / `chem` 普通化学
- `mech` 理论力学 / `matm` 材料力学 / `fluid` 流体力学
- `comp` 计算机应用基础 / `elec` 电子电工技术 / `econ` 工程经济
- `circ` 电路与电磁场 / `analog` 模拟电子技术 / `dig` 数字电子技术 / `pwr` 电气工程基础

示例：`math-l-hopital`、`circ-kirchhoff`、`pwr-three-phase`

## 工作流

```
发现知识点 → 建 card → 填 frontmatter → 写正文 → 加 related → 标记 status
```

复习时：
- 按 `status: reviewed` 过滤 → 自测 → 通过则升级为 `mastered`
- 真题练习 → 标记错因 → 回溯对应 concept/formula 卡

## 检索方式

- **全文搜索**：直接用 VSCode / Obsidian / `grep`
- **按 ID 查**：`grep -r "id: xxx" .`
- **按标签查**：`grep -r "tags:.*xxx" .`
- **按状态查**：`grep -r "status: draft" .`
- **后续可扩展**：写脚本解析 frontmatter → 建 SQLite 索引 → RAG 检索
