# 真题索引

按年份和科目整理的历年真题卡片。每道真题一张卡，含题干、答案、解题路径、关联知识点。

## 真题卡片约定

### 卡片命名

```
prob-{年份}-{科目缩写}-{题号}
```

示例：`prob-2023-math-05`、`prob-2024-circ-12`

### 错题标记

在卡片 frontmatter 中加：
- `wrong: true` — 做错的题
- `wrong_reason: 概念不清/计算错误/公式记错/审题失误` — 错因分类

## 使用方法

1. **按年份刷题**：选一套真题，计时完成
2. **错题建卡**：做错的题建 problem 卡片，标记错因
3. **回溯知识点**：每道错题关联到对应的 concept/formula 卡
4. **二轮复习**：只刷错题卡，检验是否真正掌握

## 错因分类

| 类型 | 说明 | 对策 |
|------|------|------|
| 概念不清 | 知识点没理解或理解错了 | 回去看对应 concept 卡 |
| 公式记错 | 公式记混了/漏条件了 | 复习对应 formula 卡，默写 |
| 计算错误 | 思路对了算错了 | 加强计算训练，检查习惯 |
| 审题失误 | 题目没看清条件/问的是什么 | 读题慢一点，圈关键词 |
| 方法不对 | 知道考点但选了笨方法 | 学习更优解法，积累技巧 |
