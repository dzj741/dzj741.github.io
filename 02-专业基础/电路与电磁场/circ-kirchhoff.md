# 基尔霍夫定律

## 核心定义

基尔霍夫定律是电路理论中最基本的定律，包括**电流定律（KCL）**和**电压定律（KVL）**。

### 基尔霍夫电流定律（KCL）

在集总参数电路中，任一时刻，对任一节点，所有流出（或流入）该节点的支路电流的代数和等于零：

$$
\boxed{\sum_{k=1}^n i_k = 0}
$$

### 基尔霍夫电压定律（KVL）

在集总参数电路中，任一时刻，沿任一闭合回路绕行一周，各支路电压的代数和等于零：

$$
\boxed{\sum_{k=1}^n u_k = 0}
$$

## 直觉解释

**KCL 就是"电流守恒"**——节点不能储存电荷，流进来多少就得流出去多少，就像水管的三通接头，进水量等于出水量。

**KVL 就是"电压守恒"**——绕一圈回到原点，电位升高的总和等于电位降低的总和，就像爬山——从山脚出发，上上下下绕一圈回到山脚，总的上升高度等于总的下降高度。

## 基本术语

| 术语 | 定义 |
|------|------|
| 支路（Branch） | 一个二端元件或若干元件串联的一段电路 |
| 节点（Node） | 三条或三条以上支路的连接点 |
| 回路（Loop） | 由支路组成的闭合路径 |
| 网孔（Mesh） | 内部不含其他支路的回路（"孔"） |

## KCL 详解

### 两种表述

1. **代数和为零**：$\sum i = 0$（规定流出为正，流入为负，或反过来）
2. **流入 = 流出**：$\sum i_{\text{in}} = \sum i_{\text{out}}$

### 推广：广义 KCL

KCL 不仅适用于节点，也适用于**任一闭合曲面**（广义节点）。即穿过闭合曲面的所有电流的代数和为零。

例如：两个电路之间只有一条导线相连，那么这条导线中的电流一定是零（因为要满足 KCL）。

## KVL 详解

### 两种表述

1. **代数和为零**：$\sum u = 0$（规定电位升为正，电位降为负，或反过来）
2. **电压升 = 电压降**：$\sum u_{\text{升}} = \sum u_{\text{降}}$

### 列写 KVL 方程的步骤

1. 选定回路绕行方向（顺时针或逆时针）
2. 从任一点出发，沿绕行方向走一圈
3. 遇到电阻：电流方向与绕行方向相同 → 电压降（取正或负，看约定）；相反 → 电压升
4. 遇到电压源：从 - 到 + → 电压升；从 + 到 - → 电压降
5. 所有电压加起来等于零

### 推广：广义 KVL

KVL 不仅适用于闭合回路，也适用于**任一开口路径**——可以用两点间电压等于路径上各段电压的代数和。

## KCL / KVL 与元件无关

基尔霍夫定律只和电路的**拓扑结构**（连接方式）有关，和元件是什么（电阻、电容、电源等）无关。这是它的强大之处——不管什么元件，只要接成这样的电路，KCL/KVL 就成立。

- **KCL** 由电荷守恒导出
- **KVL** 由能量守恒导出

## 基尔霍夫定律的应用

### 支路电流法

以各支路电流为未知量，列 KCL 和 KVL 方程求解。

- KCL 方程数：$n-1$ 个（$n$ 个节点）
- KVL 方程数：$b - (n-1)$ 个（$b$ 条支路）
- 总方程数：$b$ 个，正好解 $b$ 个支路电流

### 节点电压法

以节点电压为未知量，本质是 KCL 的应用。

### 网孔电流法

以网孔电流为未知量，本质是 KVL 的应用。

## 典型考点

1. **KCL 计算**：已知几个支路电流，求另一个
2. **KVL 计算**：沿回路求未知电压
3. **支路电流法**：列方程求解简单电路
4. **广义 KCL/KVL**：闭合曲面或开口路径的应用
5. **功率计算**：结合欧姆定律，求元件功率

## 易错点

1. **电流方向符号搞混**：先规定参考方向，算出来正的就是和参考方向相同，负的就是相反
2. **KVL 绕行方向和电压方向搞错**：每遇到一个元件都要仔细判断是升还是降
3. **KCL 方程列少了**：$n$ 个节点只能列 $n-1$ 个独立方程，第 $n$ 个是不独立的
4. **KVL 方程列多了**：不是所有回路都是独立的，网孔数就是独立回路数
5. **参考方向和实际方向混为一谈**：参考方向是人为设定的，和实际方向不一定相同

## 典型题

**题**：电路如图所示，已知 $I_1 = 2\text{ A}$，$I_2 = 3\text{ A}$，求 $I_3$。

```
       I₁ →
   ────┬───────
        │
        ↓ I₂
        │
   ────┴───────
       I₃ →
```

（节点有三条支路：I₁流入节点，I₂流出节点，I₃流出节点）

**解**：
取节点，规定流入为正，流出为负，列 KCL：

$$
I_1 - I_2 - I_3 = 0
$$

代入已知：

$$
2 - 3 - I_3 = 0 \quad \Rightarrow \quad I_3 = -1\text{ A}
$$

负号表示 $I_3$ 的实际方向与参考方向相反（实际上是流入节点）。

**答案**：$\boxed{I_3 = 1\ \text{A}，方向：流入节点}$
