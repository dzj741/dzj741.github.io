## 科目关联

```
电路与电磁场 ─── 模拟电子技术 ─── 数字电子技术
     │
     └──────── 电气工程基础
```

- **电路**是所有电学科目的底层语言
- **模电**和**数电**是电子技术的两大分支
- **电气工程基础**是电路+电机+电力系统的综合应用

## 备考要点

- **电路与电磁场**：分值最高，是专业基础的核心，必须吃透
- **电气工程基础**：和实际工作联系紧密，有实践经验的考生有优势
- **模电**：三极管、运放是重点，公式多但有套路
- **数电**：逻辑门、触发器、时序电路，规律性强，容易拿分
- **目标策略**：电路 + 电气工程基础 = 36分，拿下这两科已经过了及格线的一半
