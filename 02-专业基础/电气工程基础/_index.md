# 电气工程基础

18题，18分。专业基础中单科分值最高，和电路与电磁场并列。内容涵盖电机、电力系统、电气设备等，是注册电气工程师的核心专业知识。

## 学习建议

1. **变压器是重点中的重点**：既有理论又有计算，内容多但体系清晰
2. **异步电机要花功夫**：等效电路、转矩公式、机械特性，是难点也是重点
3. **短路计算必须会**：标幺值法、对称分量法，是电力系统分析的基础
4. **和电路知识联动**：变压器、电机的等效电路都是电路分析的延伸
5. **概念题也很多**：电力系统的基本概念、设备、保护，不能只做计算题
