# 变压器等效电路

## 核心定义

变压器是利用**电磁感应原理**来变换交流电压、电流和阻抗的器件。它的基本结构是两个（或多个）互相绝缘的绕组套在同一个铁芯上。

**等效电路**：将变压器的电磁关系用一个电路模型来表示，把一次侧和二次侧的参数归算到同一侧，以便用电路的方法分析计算。

## 直觉解释

把变压器想象成一个**"齿轮变速箱"**：
- 一次侧是输入端（主动轮），二次侧是输出端（从动轮）
- 匝数比就像齿轮比——匝数多的一侧电压高、电流小（大齿轮），匝数少的一侧电压低、电流大（小齿轮）
- 功率基本守恒（忽略损耗），就像齿轮传动中扭矩乘转速基本不变
- 但实际齿轮有摩擦、有间隙，变压器也有电阻、漏抗、励磁电流——这些就是等效电路中各个元件的来源

## 变压器的基本方程

### 电压比

$$
k = \frac{N_1}{N_2} \approx \frac{U_{1N}}{U_{2N}}
$$

$k$ 称为**变比**，等于一、二次绕组匝数之比，近似等于额定电压之比。

### 磁动势平衡

$$
\dot{I}_1 N_1 + \dot{I}_2 N_2 = \dot{I}_0 N_1
$$

即：一次磁动势 + 二次磁动势 = 励磁磁动势

负载时，二次电流产生的磁动势会被一次电流的增量自动抵消，主磁通基本不变。

### 电压平衡

一次侧：$\dot{U}_1 = -\dot{E}_1 + \dot{I}_1(R_1 + jX_1)$

二次侧：$\dot{U}_2 = \dot{E}_2 - \dot{I}_2(R_2 + jX_2)$

其中：
- $R_1、R_2$ — 一、二次绕组的电阻
- $X_1、X_2$ — 一、二次绕组的漏电抗
- $\dot{E}_1、\dot{E}_2$ — 一、二次绕组的感应电动势
- $\dot{I}_0$ — 励磁电流

## 归算（折算）

为了把两个不同电压等级的电路画在一起，需要把二次侧的参数**归算**到一次侧（或反过来）。

归算原则：**保持磁动势和功率不变**。

### 二次侧参数归算到一次侧（加 ' 表示归算值）

| 量 | 归算公式 | 说明 |
|----|----------|------|
| 电动势 | $\dot{E}'_2 = k\dot{E}_2$ | 乘 k |
| 电压 | $\dot{U}'_2 = k\dot{U}_2$ | 乘 k |
| 电流 | $\dot{I}'_2 = \dot{I}_2 / k$ | 除以 k |
| 电阻 | $R'_2 = k^2 R_2$ | 乘 k² |
| 电抗 | $X'_2 = k^2 X_2$ | 乘 k² |
| 阻抗 | $Z'_2 = k^2 Z_2$ | 乘 k² |
| 负载阻抗 | $Z'_L = k^2 Z_L$ | 乘 k² |

**记忆**：电压电流乘除 k，阻抗（电阻电抗）乘 k²。

## T 型等效电路

把二次侧参数归算到一次侧后，可以画出变压器的 T 型等效电路：

```
  R₁    X₁       R'₂  X'₂
──┬─/\/\/\─┬──/\/\/\─┬──
  │        │          │
  │       ┌┴┐         │
U₁      Rm Xm       Z'L
  │       └┬┘         │
  │        │          │
──┴────────┴──────────┴──
        励磁支路       负载
```

- **左侧**：一次绕组的漏阻抗 $Z_1 = R_1 + jX_1$
- **中间并联支路**：励磁支路，$Z_m = R_m + jX_m$
  - $R_m$ — 励磁电阻（对应铁耗）
  - $X_m$ — 励磁电抗（对应主磁通的磁化电抗）
- **右侧**：归算后的二次漏阻抗 + 负载阻抗

## 简化等效电路

在工程计算中，由于励磁电流 $I_0$ 远小于额定电流（仅 2~5%），可以把励磁支路移到电源端，得到**Γ型等效电路**，或者更简化的——忽略励磁电流，得到**简化等效电路**：

```
   R_k      X_k
──/\/\/\/\/\/\/\──────
                     │
                    Z'L
                     │
──────────────────────
```

其中：

$$
R_k = R_1 + R'_2, \qquad X_k = X_1 + X'_2
$$

$Z_k = R_k + jX_k$ 称为**短路阻抗**。

**什么时候用简化电路？** 负载运行、短路计算时，I0 可以忽略，简化电路精度足够。

## 标幺值

在变压器和电力系统计算中，常用**标幺值**（相对值）代替有名值。

$$
\text{标幺值} = \frac{\text{有名值}}{\text{基准值}}
$$

通常取额定值作为基准值：
- 电压基准：$U_B = U_N$
- 电流基准：$I_B = I_N$
- 阻抗基准：$Z_B = U_N / I_N$
- 功率基准：$S_B = S_N$

**标幺值的优点**：
1. 不同电压等级的参数不用归算，直接比较
2. 数值范围小，容易判断是否合理
3. 计算简化

## 电压调整率

电压调整率（电压变化率）是衡量变压器供电质量的重要指标：

$$
\Delta U\% = \frac{U_{2N} - U_2}{U_{2N}} \times 100\%
$$

用标幺值计算：

$$
\Delta U = \beta (R_k^* \cos\varphi_2 + X_k^* \sin\varphi_2)
$$

其中：
- $\beta = I_2 / I_{2N}$ — 负载系数
- $\cos\varphi_2$ — 负载功率因数
- $R_k^*、X_k^*$ — 短路电阻、短路电抗的标幺值

**物理意义**：负载时二次端电压比空载时下降了多少。电阻压降和电抗压降共同作用，电阻压降和电流同相，电抗压降超前 90°。

## 效率

$$
\eta = \frac{P_2}{P_1} = \frac{P_2}{P_2 + p_{Fe} + p_{Cu}}
$$

其中：
- $P_2 = \beta S_N \cos\varphi_2$ — 输出功率
- $p_{Fe}$ — 铁耗（空载损耗，基本不变）
- $p_{Cu} = \beta^2 p_{kN}$ — 铜耗（短路损耗，和负载电流平方成正比）

**最大效率条件**：当可变损耗（铜耗）等于不变损耗（铁耗）时，效率最大：
$$
p_{Fe} = \beta^2_m p_{kN} \quad \Rightarrow \quad \beta_m = \sqrt{\frac{p_{Fe}}{p_{kN}}}
$$

一般电力变压器的最大效率出现在负载系数 $\beta \approx 0.5 \sim 0.6$ 处。

## 典型考点

1. **变比计算**：匝数比、电压比、电流比的关系
2. **归算计算**：二次侧参数归算到一次侧
3. **T型/简化等效电路**：电路结构和参数意义
4. **电压调整率**：公式计算，和功率因数的关系
5. **效率与最大效率**：效率公式、最大效率条件
6. **标幺值计算**：标幺值和有名值的换算
7. **空载试验与短路试验**：由试验数据求等效电路参数

## 易错点

1. **归算方向搞反**：归算到高压侧乘 k²，归算到低压侧除 k²，别搞反了
2. **变比的定义**：一次比二次还是二次比一次？不同教材可能不同，注意定义
3. **电压调整率公式记错**：感性负载时 sinφ 取正，容性负载时 sinφ 取负（可能出现负的电压调整率）
4. **铁耗和铜耗的特性搞混**：铁耗基本不变（和电压有关），铜耗随负载平方变（和电流有关）
5. **最大效率条件记错**：是铜耗=铁耗，不是额定负载时效率最高
6. **标幺值基准选错**：各物理量的基准值之间要满足欧姆定律，不能乱选

## 典型题

**题**：一台单相变压器，额定容量 $S_N = 100\text{ kVA}$，额定电压 $U_{1N}/U_{2N} = 6000/230\text{ V}$，空载试验测得铁耗 $p_{Fe} = 600\text{ W}$，短路试验测得额定铜耗 $p_{kN} = 2400\text{ W}$。当负载系数 $\beta = 0.5$、$\cos\varphi_2 = 0.8$（感性）时，求变压器的效率。

**解**：

输出功率：
$$
P_2 = \beta S_N \cos\varphi_2 = 0.5 \times 100000 \times 0.8 = 40000\text{ W} = 40\text{ kW}
$$

铁耗（不变损耗）：
$$
p_{Fe} = 600\text{ W} = 0.6\text{ kW}
$$

铜耗（可变损耗）：
$$
p_{Cu} = \beta^2 p_{kN} = 0.5^2 \times 2400 = 0.25 \times 2400 = 600\text{ W} = 0.6\text{ kW}
$$

效率：
$$
\eta = \frac{P_2}{P_2 + p_{Fe} + p_{Cu}} = \frac{40}{40 + 0.6 + 0.6} = \frac{40}{41.2} \approx 97.09\%
$$

（验证：此时铜耗=铁耗，效率达到最大，符合最大效率条件）

**答案**：$\boxed{\eta \approx 97.1\%}$
