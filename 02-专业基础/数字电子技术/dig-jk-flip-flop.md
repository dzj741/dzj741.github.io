# JK 触发器

## 核心定义

JK 触发器是一种功能最完善的触发器，具有**置 0、置 1、保持、翻转**四种功能。它解决了 RS 触发器中 R 和 S 不能同时为 1 的约束问题。

## 直觉解释

把 JK 触发器想象成一个**"带记忆的开关"**：
- 它有一个状态 $Q$（0 或 1），就是它记住的内容
- $J$ 是"置 1 端"——想让它变成 1，就让 J=1
- $K$ 是"置 0 端"——想让它变成 0，就让 K=1
- 时钟 CLK 是"行动信号"——只有时钟来的时候，J 和 K 才起作用

最特别的是**翻转功能**（J=1, K=1）：每次时钟来一下，状态就翻个个儿（0→1，1→0），就像按开关——按一下开，再按一下关。这个功能用来做计数器特别好用。

## 逻辑符号

```
     ┌───────┐
  J ─┤ J     │
     │       │ Q ──→
CLK ─┤  >    │
     │       │ Q' ─→
  K ─┤ K     │
     └───────┘
```

- **J、K**：数据输入端
- **CLK**：时钟输入端（三角形表示边沿触发）
- **Q、Q'**：输出端（Q 是原码输出，Q' 是反码输出）

> 注意：如果 CLK 端有小圆圈，表示**下降沿触发**（时钟从 1 变 0 时有效）；没有小圆圈，表示**上升沿触发**（时钟从 0 变 1 时有效）。考试里以**下降沿触发**的 JK 触发器最常见。

## 特性表（真值表）

下降沿触发的 JK 触发器特性表：

| J | K | $Q^n$ | $Q^{n+1}$ | 功能说明 |
|---|---|-------|-----------|----------|
| 0 | 0 | 0 | 0 | 保持 |
| 0 | 0 | 1 | 1 | 保持 |
| 0 | 1 | 0 | 0 | 置 0 |
| 0 | 1 | 1 | 0 | 置 0 |
| 1 | 0 | 0 | 1 | 置 1 |
| 1 | 0 | 1 | 1 | 置 1 |
| 1 | 1 | 0 | 1 | 翻转（计数） |
| 1 | 1 | 1 | 0 | 翻转（计数） |

$Q^n$ 是时钟到来之前的状态（现态），$Q^{n+1}$ 是时钟之后的状态（次态）。

## 特性方程

$$
\boxed{Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n}
$$

（只在时钟有效沿时成立）

**怎么记？**
- J 和 $\overline{Q^n}$ 搭配（置 1 要看现态是不是 0）
- $\overline{K}$ 和 $Q^n$ 搭配（保持要看 K 是不是 0）
- 两者相加，就是次态

## 四种功能总结

| J | K | 功能 | 次态 |
|---|---|------|------|
| 0 | 0 | 保持 | $Q^{n+1} = Q^n$ |
| 0 | 1 | 置 0 | $Q^{n+1} = 0$ |
| 1 | 0 | 置 1 | $Q^{n+1} = 1$ |
| 1 | 1 | 翻转 | $Q^{n+1} = \overline{Q^n}$ |

**口诀**：
- "00 不变，01 置零，10 置一，11 翻转"

## 驱动表（激励表）

已知现态 $Q^n$ 和次态 $Q^{n+1}$，求需要的 J、K 输入：

| $Q^n$ | $Q^{n+1}$ | J | K | 说明 |
|-------|-----------|---|---|------|
| 0 | 0 | 0 | × | 保持 0，J必须为0，K随意 |
| 0 | 1 | 1 | × | 0→1，J必须为1，K随意 |
| 1 | 0 | × | 1 | 1→0，K必须为1，J随意 |
| 1 | 1 | × | 0 | 保持 1，K必须为0，J随意 |

× 表示"任意"（可以是 0 也可以是 1）。

驱动表在**设计时序电路**（比如设计计数器）的时候特别有用。

## 时序图画法

画时序图的步骤：
1. 画出时钟 CLK 波形
2. 确定初始状态 $Q$ 的初值
3. 在每个时钟有效沿（比如下降沿），根据当时的 J、K 值，更新 Q 的状态
4. 注意：只有时钟有效沿时状态才变，其他时候保持

## 典型应用

### 1. 构成 T 触发器

令 J=K=T，就得到 T 触发器：
- T=0 时保持
- T=1 时翻转

令 J=K=1（永远接高电平），就得到 T' 触发器（翻转触发器），每来一个时钟翻转一次，可用于分频和计数。

### 2. 构成计数器

多个 JK 触发器级联，可以构成各种进制的计数器（二进制、十进制、任意进制）。

### 3. 构成移位寄存器

把前一级的 Q 接到后一级的 J，$\overline{Q}$ 接到 K（或者用 D 触发器更方便），就构成移位寄存器。

## 典型考点

1. **特性表/特性方程**：给定 J、K 和现态，求次态
2. **时序图绘制**：给定输入波形，画输出波形
3. **驱动表**：已知状态转换，求 J、K 激励
4. **计数器分析**：用 JK 触发器构成的计数器，分析进制
5. **触发器转换**：JK → D、JK → T 的转换
6. **触发方式判断**：上升沿还是下降沿，看符号和波形

## 易错点

1. **触发沿搞反**：有小圆圈是下降沿触发，没小圆圈是上升沿触发
2. **异步端忽略**：有些触发器有异步置位/复位端（$\overline{S}_D$、$\overline{R}_D$），优先级比时钟高
3. **状态更新时间搞错**：只有时钟有效沿那一刻才更新，不是整个高/低电平时都变
4. **J、K 悬空**：TTL 电路输入端悬空相当于接高电平，CMOS 不能悬空
5. **和 D 触发器混淆**：D 触发器是"次态=输入D"，JK 有四种功能，别混了

## 典型题

**题**：下降沿触发的 JK 触发器，初始状态 $Q=0$，若 J=1、K=1，连续输入 3 个时钟脉冲后，$Q$ 的状态为（ ）

A. 0  
B. 1  
C. 不定  
D. 以上都不对

**解**：
J=1、K=1 时，JK 触发器处于**翻转功能**，每来一个时钟脉冲翻转一次。

初始状态：$Q=0$

- 第 1 个时钟下降沿：$0 \to 1$
- 第 2 个时钟下降沿：$1 \to 0$
- 第 3 个时钟下降沿：$0 \to 1$

3 个时钟后 $Q=1$。

**答案**：$\boxed{B}$
