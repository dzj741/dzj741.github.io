# 施工成本控制 - 赢得值法

> [!important] 考点说明
> - **重要程度**：⭐⭐⭐⭐⭐
> - **历年分值**：3-5分
> - - **考察形式**：单选 + 多选 + 计算
> - **真题年份**：每年必考，计算是重点

---

## 一、赢得值法的三个基本参数

### 1. 已完工作预算费用（BCWP）
已完工作预算费用（Budgeted Cost for Work Performed），是指在某一时间已经完成的工作（或部分工作），以批准认可的预算为标准所需要的资金总额。

$$BCWP = 已完成工作量 \times 预算单价$$

> [!tip] 记忆
> **已完工作预算** = 实际干了多少活 × 预算单价

### 2. 计划工作预算费用（BCWS）
计划工作预算费用（Budgeted Cost for Work Scheduled），即根据进度计划，在某一时刻应当完成的工作（或部分工作），以预算为标准所需要的资金总额。

$$BCWS = 计划工作量 \times 预算单价$$

> [!tip] 记忆
> **计划工作预算** = 计划干多少活 × 预算单价

### 3. 已完工作实际费用（ACWP）
已完工作实际费用（Actual Cost for Work Performed），即到某一时刻为止，已完成的工作（或部分工作）所实际花费的总金额。

$$ACWP = 已完成工作量 \times 实际单价$$

> [!tip] 记忆
> **已完工作实际** = 实际干了多少活 × 实际单价

---

## 二、赢得值法的四个评价指标

### 1. 费用偏差（CV）
$$CV = BCWP - ACWP = 已完工作预算费用 - 已完工作实际费用$$

> [!note] 判别标准
> - **CV > 0**：费用节支（实际费用低于预算）
> - **CV < 0**：费用超支（实际费用超出预算）
> - **CV = 0**：费用与预算一致

### 2. 进度偏差（SV）
$$SV = BCWP - BCWS = 已完工作预算费用 - 计划工作预算费用$$

> [!note] 判别标准
> - **SV > 0**：进度提前（实际进度快于计划进度）
> - **SV < 0**：进度延误（实际进度落后于计划进度）
> - **SV = 0**：进度与计划一致

### 3. 费用绩效指数（CPI）
$$CPI = \frac{BCWP}{ACWP} = \frac{已完工作预算费用}{已完工作实际费用}$$

> [!note] 判别标准
> - **CPI > 1**：费用节支
> - **CPI < 1**：费用超支
> - **CPI = 1**：费用与预算一致

### 4. 进度绩效指数（SPI）
$$SPI = \frac{BCWP}{BCWS} = \frac{已完工作预算费用}{计划工作预算费用}$$

> [!note] 判别标准
> - **SPI > 1**：进度提前
> - **SPI < 1**：进度延误
> - **SPI = 1**：进度与计划一致

---

## 三、记忆口诀

> [!tip] 快速记忆
> 
> **三个参数**：
> - BCWP：已完预算（已干的活，按预算算）
> - BCWS：计划预算（计划干的活，按预算算）
> - ACWP：已完实际（已干的活，按实际算）
> 
> **四个指标**：
> - CV = BCWP - ACWP（费用偏差：已完预算 - 已完实际）
> - SV = BCWP - BCWS（进度偏差：已完预算 - 计划预算）
> - CPI = BCWP / ACWP（费用指数：已完预算 / 已完实际）
> - SPI = BCWP / BCWS（进度指数：已完预算 / 计划预算）
> 
> **都是 BCWP 减/除以 另一个！**

## 四、偏差分析的表达方法

### 1. 横道图法
- 形象直观，一目了然
- 能够准确表达费用的绝对偏差
- 反映的信息量少，一般在项目的较高管理层应用

### 2. 表格法
- 灵活、适用性强
- 信息量大
- 可借助计算机处理

### 3. 曲线法
- 形象、直观
- 能够直接表达偏差情况
- 很难直接用于定量分析

## 五、偏差原因分析与纠偏措施

### 1. 偏差原因

| 类别 | 具体原因 |
|------|----------|
| 物价上涨 | 人工费涨价、材料费涨价、设备费涨价、其他 |
| 设计原因 | 设计错误、设计漏项、设计标准变化、设计保守、图纸提供不及时 |
| 业主原因 | 增加内容、投资规划不当、组织不落实、建设手续不全、协调不佳、未及时提供场地 |
| 施工原因 | 施工方案不当、材料代用、施工质量有问题、赶进度、工期拖延 |
| 客观原因 | 自然因素、基础处理、社会原因、法规政策变化 |

## 📝 历年真题

> [!faq] 2023年真题
> **题目**：某土方工程，月计划工程量2800m³，预算单价25元/m³；到月末时已完成工程量3000m³，实际单价26元/m³。对该项工作采用赢得值法进行偏差分析，下列说法正确的是（  ）。
> 
> A. 已完成工作实际费用为75000元
> B. 费用绩效指数>1，表明项目运行超出预算费用
> C. 进度绩效指数<1，表明项目运行延误
> D. 费用偏差为-3000元，表明项目运行超出预算费用
> 
> **答案**：D
> 
> **解析**：
> BCWP = 3000 × 25 = 75000 元
> BCWS = 2800 × 25 = 70000 元
> ACWP = 3000 × 26 = 78000 元
> 
> CV = 75000 - 78000 = -3000 元 < 0，费用超支
> SV = 75000 - 70000 = 5000 元 > 0，进度提前
> CPI = 75000 / 78000 ≈ 0.96 < 1，费用超支
> SPI = 75000 / 70000 ≈ 1.07 > 1，进度提前
> 
> 所以D正确。

> [!faq] 2022年真题
> **题目**：某工程计划工作预算费用为3000万元，已完工作预算费用为2800万元，已完工作实际费用为2900万元。则该工程的（  ）。
> A. 费用偏差为-100万元，费用超支
> B. 费用偏差为100万元，费用节支
> C. 进度偏差为-200万元，进度延误
> D. 进度绩效指数为0.93，进度延误
> E. 费用绩效指数为0.97，费用超支
> 
> **答案**：ACDE
> 
> **解析**：
> BCWS = 3000万元
> BCWP = 2800万元
> ACWP = 2900万元
> 
> CV = 2800 - 2900 = -100万元 < 0，费用超支 → A对，B错
> SV = 2800 - 3000 = -200万元 < 0，进度延误 → C对
> CPI = 2800 / 2900 ≈ 0.97 < 1，费用超支 → E对
> SPI = 2800 / 3000 ≈ 0.93 < 1，进度延误 → D对
