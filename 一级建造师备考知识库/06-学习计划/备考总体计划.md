# 一级建造师备考总体计划

> [!info] 计划说明
> - **备考目标**：一次性通过四科
> - **备考周期**：约6个月（建议）
> - **总学习时长**：约500-600小时
> - **每日学习时间**：2-3小时（工作日）+ 4-6小时（周末）

---

## 🎯 总体目标

> [!success] 目标设定
> - **建设工程经济**：75分+
> - **建设工程法规及相关知识**：95分+
> - **建设工程项目管理**：95分+
> - **建筑工程管理与实务**：110分+

---

## 📅 四个学习阶段

```mermaid
graph LR
    A[基础阶段<br/>约2个月] --> B[强化阶段<br/>约1.5个月]
    B --> C[冲刺阶段<br/>约1.5个月]
    C --> D[模考阶段<br/>约1个月]
```

### 第一阶段：基础阶段（约2个月）

> [!note] 阶段目标
> 通读教材，建立知识框架，理解基本概念

- [ ] 建设工程经济教材通读
- [ ] 建设工程法规及相关知识教材通读
- [ ] 建设工程项目管理教材通读
- [ ] 建筑工程管理与实务教材通读
- [ ] 配套基础班视频课程
- [ ] 每章课后习题

**学习顺序建议**：
1. 工程经济 → 打基础
2. 工程法规 → 理解法律框架
3. 项目管理 → 掌握管理体系
4. 建筑实务 → 融会贯通（最难，留到最后）

**每日学习时长**：2-3小时

### 第二阶段：强化阶段（约1.5个月）

> [!note] 阶段目标
> 重点突破，掌握高频考点，深入理解重难点

- [ ] 重点章节精读
- [ ] 高频考点专项突破
- [ ] 强化班课程学习
- [ ] 章节习题强化训练
- [ ] 建立错题本

**重点突破章节**：
- **经济**：第三章建设工程估价（50分）
- **法规**：第一章、第三章、第四章、第八章
- **管理**：第三章进度管理、第六章合同管理
- **实务**：施工管理部分（进度、质量、安全、合同）

**每日学习时长**：3小时

### 第三阶段：冲刺阶段（约1.5个月）

> [!note] 阶段目标
> 真题实战，查漏补缺，提升应试能力

- [ ] 近5年真题（第一遍）
- [ ] 真题考点回归教材
- [ ] 高频考点背诵
- [ ] 错题二刷
- [ ] 案例题专项训练（实务）

**真题使用方法**：
- 严格按照考试时间模拟
- 做完后认真分析错题
- 回归教材对应知识点
- 记录真题考点

**每日学习时长**：3-4小时

### 第四阶段：模考阶段（约1个月）

> [!note] 阶段目标
> 模拟考试，调整状态，最后冲刺

- [ ] 近5年真题（第二遍）
- [ ] 模拟题/押题卷
- [ ] 错题回顾
- [ ] 重要考点速记
- [ ] 调整作息和心态

**考前一周**：
- 每天一套模拟题
- 回顾错题本
- 看冲刺讲义
- 调整心态，保证睡眠

**每日学习时长**：4-6小时

## ⏰ 时间分配建议

| 科目 | 建议学习时长 | 占比 |
|------|-------------|------|
| 建设工程经济 | 80-100小时 | ~17% |
| 建设工程法规及相关知识 | 100-120小时 | ~20% |
| 建设工程项目管理 | 100-120小时 | ~20% |
| 建筑工程管理与实务 | 220-260小时 | ~43% |
| **合计** | **500-600小时** | **100%** |

> [!warning] 重要提醒
> 建筑实务是最难的科目，也是最容易卡人的科目。
> 务必投入**至少40%**的备考时间在实务上！

## 💡 备考建议

> [!tip] 高效学习方法
> 1. **艾宾浩斯遗忘曲线**：及时复习，反复记忆
> 2. **番茄工作法**：25分钟专注学习 + 5分钟休息
> 3. **费曼学习法**：用自己的话讲出来，检验是否真的理解
> 4. **思维导图**：建立知识框架，理清知识脉络
> 5. **错题本**：错题是最好的老师，定期回顾

> [!warning] 避坑指南
> 1. 不要只看视频不动手
> 2. 不要只刷题不回归教材
> 3. 不要忽视真题的价值
> 4. 不要偏科，四科都要过线
> 5. 不要临考抱佛脚，实务要早准备
