# 工程经济

10题，10分。研究工程项目的经济效果评价方法。

## 知识大纲

### 1. 资金的时间价值
- 现金流量与资金等值
- 利息与利率
- 资金等值计算（六大公式）

### 2. 项目经济效果评价
- 静态评价指标
- 动态评价指标（NPV、IRR 等）
- 方案比选

### 3. 不确定性分析
- 盈亏平衡分析
- 敏感性分析
- 概率分析

### 4. 价值工程
- 价值工程概念
- 对象选择与功能分析
- 方案创新与评价

### 5. 项目财务评价与国民经济评价
- 财务评价
- 国民经济评价
- 费用效益分析

## 学习建议

1. **六大公式必须背**：资金等值计算的六个公式是工程经济的根基
2. **NPV 和 IRR 是重点**：必考，理解概念 + 掌握计算
3. **盈亏平衡有套路**：公式记住就能拿分
4. **价值工程抓概念**：V=F/C，提高价值的途径，常考概念题
5. **多做真题**：工程经济题型相对固定，真题练熟了就稳
