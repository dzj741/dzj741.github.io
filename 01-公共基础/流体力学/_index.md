# 流体力学

12题，12分。研究流体的平衡和运动规律。

## 知识大纲

### 1. 流体的主要物理性质与流体静力学
- 流体的黏性、压缩性
- 流体静压强
- 流体静力学基本方程
- 作用在平面和曲面上的静水总压力

### 2. 流体动力学基础
- 描述流体运动的方法
- 连续性方程
- 能量方程（伯努利方程）
- 动量方程

### 3. 流动阻力和水头损失
- 层流与湍流
- 沿程水头损失
- 局部水头损失

### 4. 孔口、管嘴出流与有压管流
- 孔口出流
- 管嘴出流
- 简单管道的水力计算
- 串联、并联管道

### 5. 明渠恒定流
- 明渠均匀流
- 明渠非均匀流

### 6. 渗流
- 渗流基本概念
- 达西定律
- 井的渗流计算

## 学习建议

1. **三大方程是核心**：连续性方程、能量方程、动量方程，是流体力学的骨架
2. **伯努利方程要精通**：应用最广，必考，各种题型都有
3. **水头损失有公式**：达西公式、局部阻力系数，记住就能算
4. **和材料力学对比学**：流体的"压强、水头"对应材料力学的"应力、变形"，思路有相通之处
