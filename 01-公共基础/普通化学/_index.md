# 普通化学

12题，12分。内容覆盖物质结构、溶液、化学反应、电化学、有机化学。

## 知识大纲

### 1. 物质结构与物质状态
- 原子结构（核外电子分布）
- 元素周期律
- 化学键与分子结构
- 晶体结构
- 气体定律

### 2. 溶液
- 溶液浓度
- 稀溶液的依数性
- 电解质溶液

### 3. 化学反应速率与化学平衡
- 反应速率方程
- 化学平衡与平衡常数
- 化学平衡移动

### 4. 氧化还原与电化学
- 氧化还原反应
- 原电池与电极电势
- 电解与腐蚀

### 5. 有机化学
- 烃类
- 烃的衍生物
- 高分子化合物

## 重点章节

| 章节 | 重要度 | 难度 | 说明 |
|------|--------|------|------|
| 化学平衡 | ★★★★ | ★★★ | 平衡常数、移动方向，必考 |
| 电化学 | ★★★★ | ★★★ | 电极电势、原电池，和物理/电工联动 |
| 物质结构 | ★★★ | ★★★ | 电子排布、周期律，概念多 |
| 溶液 | ★★★ | ★★ | 依数性是重点 |
| 有机化学 | ★★ | ★★ | 考得不多，记基本反应 |

## 学习建议

1. **化学平衡是核心**：既是重点又是难点，拿下它就拿下了化学的半壁江山
2. **电化学要重视**：和物理电磁学、电工基础有联系，学好了一举三得
3. **物质结构靠记忆**：电子排布、周期表规律，多花时间背
4. **有机不用深挖**：考得少，掌握基本概念和常见反应就行
