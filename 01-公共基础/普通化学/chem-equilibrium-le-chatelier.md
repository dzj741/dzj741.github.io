# 化学平衡与勒夏特列原理

## 核心定义

**化学平衡**：在一定条件下的可逆反应中，正反应速率等于逆反应速率，反应物和生成物的浓度不再随时间改变的状态。

**勒夏特列原理**：如果改变平衡系统的条件之一（浓度、压力、温度），平衡就会向能够减弱这种改变的方向移动。

## 直觉解释

化学平衡就像一架**天平**——两边等重时平衡。你在一边加点砝码（增加反应物浓度），天平就歪了，系统会自动往另一边挪（反应正向进行），直到重新平衡。

勒夏特列原理就是**"对着干"原则**：你升温，我就往吸热方向移来降温；你加压，我就往气体分子数少的方向移来减压。总而言之，你怎么变我都要削弱你的变化，但**注意：只是削弱，不能完全抵消**。

## 平衡常数

### 经验平衡常数 $K_c$ / $K_p$

对于可逆反应：

$$
a\text{A} + b\text{B} \rightleftharpoons c\text{C} + d\text{D}
$$

平衡时：

$$
K_c = \frac{[\text{C}]^c [\text{D}]^d}{[\text{A}]^a [\text{B}]^b} \qquad K_p = \frac{p_\text{C}^c p_\text{D}^d}{p_\text{A}^a p_\text{B}^b}
$$

**注意**：
- 纯固体、纯液体、稀溶液中的溶剂不出现在平衡常数表达式中（活度为 1）
- $K$ 只与**温度**有关，与浓度/压力无关
- $K$ 越大，正向反应越完全

### 标准平衡常数 $K^\ominus$

用相对浓度 $[\text{B}]/c^\ominus$ 或相对分压 $p_\text{B}/p^\ominus$ 表示，无量纲。

## 平衡常数与反应方向

**反应商 $Q$**：形式和 $K$ 一样，但用的是任意时刻的浓度/分压。

| 关系 | 反应方向 |
|------|----------|
| $Q < K$ | 正向进行 → |
| $Q = K$ | 平衡状态 ⇌ |
| $Q > K$ | 逆向进行 ← |

**记忆**：$Q$ 往 $K$ 的方向跑——$Q$ 小就变大（正向），$Q$ 大就变小（逆向）。

## 勒夏特列原理：平衡移动

### 1. 浓度对平衡的影响

- 增加反应物浓度 → 平衡正向移动
- 减少生成物浓度 → 平衡正向移动
- 增加生成物浓度 → 平衡逆向移动

**注意**：浓度改变不改变 $K$，只改变平衡位置。

### 2. 压力对平衡的影响

只对有气体参与、且反应前后气体分子数不等的反应有影响。

设 $\Delta n = $ 生成物气体分子数 $-$ 反应物气体分子数

| 变化 | $\Delta n > 0$ (气增) | $\Delta n < 0$ (气减) | $\Delta n = 0$ |
|------|----------------------|----------------------|----------------|
| 增大压力 | 逆向移动 | 正向移动 | 不移动 |
| 减小压力 | 正向移动 | 逆向移动 | 不移动 |

**口诀**：加压往气少方向移，减压往气多方向移。

### 3. 温度对平衡的影响

- 升高温度 → 平衡向**吸热**方向移动
- 降低温度 → 平衡向**放热**方向移动

**注意**：温度改变会改变 $K$ 的值。升温，吸热反应的 $K$ 增大；降温则相反。

### 4. 催化剂的影响

催化剂**不影响平衡位置**，只改变达到平衡的时间（同等程度加快正逆反应速率）。

## 平衡移动的计算思路

1. 写出配平的反应方程式
2. 列出各物质的初始浓度/分压
3. 设未知数 $x$，表示各物质的变化量（注意化学计量数）
4. 写出平衡浓度/分压的表达式
5. 代入平衡常数表达式，解方程
6. 验证结果是否合理

## 典型考点

1. **平衡常数表达式书写**：哪些物质不写入（固体、液体溶剂）
2. **平衡移动方向判断**：给定条件变化，用勒夏特列判断方向
3. **平衡常数计算**：给定平衡浓度算 $K$，或已知 $K$ 算平衡浓度
4. **反应商与平衡**：比较 $Q$ 和 $K$ 判断方向
5. **温度对 $K$ 的影响**：判断吸热/放热，$K$ 随温度怎么变

## 易错点

1. **勒夏特列只能判断方向，不能判断程度**：移动了多少要算
2. **催化剂不改变平衡**：别被"加了催化剂反应更快所以平衡右移"迷惑
3. **改变固体/纯液体的量不影响平衡**：因为浓度不变
4. **惰性气体的影响**：恒容加惰性气体 → 分压不变 → 不移动；恒压加惰性气体 → 体积变大 → 相当于减压 → 向气多方向移
5. **平衡常数只和温度有关**：浓度、压力、催化剂都不改变 $K$

## 典型题

**题**：反应 $\text{N}_2(g) + 3\text{H}_2(g) \rightleftharpoons 2\text{NH}_3(g) + Q$（放热反应），已达平衡。下列操作能使平衡正向移动的是（ ）

A. 升高温度  
B. 减小压力  
C. 加入催化剂  
D. 移走 $\text{NH}_3$

**解**：逐项分析：
- A. 升温 → 放热反应逆向移动（往吸热方向即逆向移） ❌
- B. 减压 → $\Delta n = 2-4 = -2 < 0$（气减），减压往气多方向即逆向移 ❌
- C. 催化剂 → 不改变平衡 ❌
- D. 移走 $\text{NH}_3$（减少生成物浓度）→ 平衡正向移动 ✅

**答案**：$\boxed{D}$
