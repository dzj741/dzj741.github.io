# 计算机应用基础

10题，10分。内容以计算机基础知识和简单应用为主。

## 知识大纲

### 1. 计算机系统组成
- 计算机硬件系统
- 计算机软件系统
- 计算机工作原理

### 2. 数制与编码
- 数制转换（二、八、十、十六进制）
- 数据编码（ASCII、汉字编码）

### 3. Windows 操作系统
- 基本操作
- 文件管理
- 系统设置

### 4. 计算机网络
- 网络基本概念
- Internet 基础
- 网络安全

### 5. 常用软件
- Word 文字处理
- Excel 电子表格
- PowerPoint 演示文稿

### 6. 程序设计基础
- 程序设计基本概念
- 简单算法与流程图

## 学习建议

1. **数制转换要练熟**：这是最容易拿分的计算题，必须掌握
2. **概念题靠积累**：计算机基础概念多，分散，多做真题积累
3. **网络知识是重点**：IP地址、TCP/IP、OSI七层模型，常考
4. **程序设计抓基础**：流程图、算法基本结构，不用深但要懂
