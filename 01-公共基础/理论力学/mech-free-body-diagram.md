# 受力分析与静力学平衡

## 核心定义

**受力分析**：将研究对象从周围物体中隔离出来，分析它受到的所有力，并画在图上（受力图）。

**静力学平衡**：物体相对于惯性系保持静止或匀速直线运动的状态。此时合力为零，合力偶也为零。

## 直觉解释

静力学平衡就像**拔河——两边势均力敌，谁也拉不动谁**。只不过这里不只有拉力，还有各种力、各个方向。当所有力在 x 方向加起来等于零、y 方向加起来等于零、力矩加起来也等于零时，物体就"定住了"。

**受力分析的核心是"隔离"**——你要研究哪个物体，就把它"拎出来"，周围物体对它的作用全部用力来代替。画错一个力，后面全错。

## 常见约束与约束力

| 约束类型 | 简图 | 约束力 | 未知量数 |
|----------|------|--------|----------|
| 柔索（绳索/皮带） | — | 沿柔索，背离物体（拉力） | 1 |
| 光滑接触面 | ╱╲ | 沿法线，指向物体（压力） | 1 |
| 光滑圆柱铰链（铰结点） | ● | 水平+竖直两个分量 | 2 |
| 固定铰支座 | △ | 水平+竖直两个分量 | 2 |
| 可动铰支座（滚动支座） | ○ | 垂直于支撑面 | 1 |
| 固定端（插入端） | ═ | 水平力+竖直力+力偶 | 3 |
| 二力杆（只受两力平衡的构件） | — | 沿杆轴线 | 1 |

**记忆技巧**：
- 限制什么方向的运动，就有什么方向的约束力
- 光滑 = 没有摩擦力，只有法向力
- 二力杆 = 两端铰接 + 中间不受力 = 力沿杆轴

## 受力图绘制步骤

1. **确定研究对象**：单个物体还是整体？还是局部？
2. **解除约束，画出隔离体**：把研究对象单独画出来
3. **画主动力**：重力、荷载等，一般是已知的
4. **画约束力**：逐个约束分析，根据约束类型画对应的约束力
5. **检查**：力不能多也不能少；每一个力都要有施力物体

## 平面力系的平衡方程

### 基本形式（一矩式）

$$
\boxed{
\begin{cases}
\sum F_x = 0 \\
\sum F_y = 0 \\
\sum M_O(\vec{F}) = 0
\end{cases}
}
$$

即：x 方向合力为零，y 方向合力为零，对任意点 O 的力矩之和为零。

### 二矩式

$$
\begin{cases}
\sum F_x = 0 \\
\sum M_A(\vec{F}) = 0 \\
\sum M_B(\vec{F}) = 0
\end{cases}
$$

**条件**：A、B 两点的连线不能垂直于 x 轴。

### 三矩式

$$
\begin{cases}
\sum M_A(\vec{F}) = 0 \\
\sum M_B(\vec{F}) = 0 \\
\sum M_C(\vec{F}) = 0
\end{cases}
$$

**条件**：A、B、C 三点不能共线。

**选用技巧**：有两个未知力相交 → 对交点取矩，消掉两个未知量，一步求出第三个。

## 静力学解题一般步骤

1. **选研究对象**：整体还是局部？先整体后局部是常用技巧
2. **画受力图**：准确、完整，不多不少
3. **列平衡方程**：选合适的坐标系和矩心，尽量一个方程解一个未知量
4. **解方程**：注意正负号
5. **校核**：用多余的平衡方程验证结果

## 典型考点

1. **画受力图**：选择题里判断受力图正确与否
2. **简支梁/悬臂梁求支座反力**：最经典的静力学题
3. **桁架杆件内力**：节点法或截面法
4. **物体系平衡**：多个物体组成的系统，先整体后局部
5. **摩擦平衡**：考虑静摩擦的临界情况

## 易错点

1. **作用力与反作用力搞混**：分析两个物体之间的作用力时，方向要相反
2. **内力画到受力图上**：研究对象内部各部分之间的力是内力，不画
3. **铰链处的力方向瞎猜**：先设为 x、y 两个分量，算出来正的就是对的，负的就说明反了
4. **二力杆判断错**：不是所有杆都是二力杆，必须满足"两端铰+中间不受力"
5. **力矩符号错**：一般规定逆时针为正，顺时针为负，统一就好
6. **分布荷载忘了换成集中力**：均布荷载 $q$ 作用长度 $L$，合力为 $qL$，作用点在中点

## 典型题

**题**：简支梁 AB，跨度为 $L$，受均布荷载 $q$ 作用，求 A、B 支座反力。

**解**：
1. 研究对象：梁 AB
2. 受力分析：
   - 主动力：均布荷载 $q$，合力 $Q = qL$，作用于梁中点
   - A 为固定铰支座：$F_{Ax}$、$F_{Ay}$
   - B 为可动铰支座：$F_{By}$（竖直向上）
3. 列平衡方程：
   - $\sum F_x = 0$：$F_{Ax} = 0$
   - $\sum M_A = 0$：$F_{By} \cdot L - qL \cdot \frac{L}{2} = 0$ → $F_{By} = \frac{qL}{2}$
   - $\sum F_y = 0$：$F_{Ay} + F_{By} - qL = 0$ → $F_{Ay} = qL - \frac{qL}{2} = \frac{qL}{2}$
4. 结果：A 点反力竖直向上 $\frac{qL}{2}$，B 点反力竖直向上 $\frac{qL}{2}$

**答案**：$\boxed{F_{Ay} = F_{By} = \dfrac{qL}{2} (\uparrow),\ F_{Ax} = 0}$
