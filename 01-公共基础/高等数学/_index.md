# 高等数学

24题，24分，公共基础中单科分值最高。是物理、力学、电路等科目的数学基础。

## 知识大纲

### 1. 空间解析几何
- 向量代数
- 直线与平面
- 柱面、旋转曲面、二次曲面
- 空间曲线

### 2. 微分学
- 极限与连续
- 导数与微分
- 偏导数与全微分
- 导数与微分的应用（极值、曲率等）

### 3. 积分学
- 不定积分与定积分
- 广义积分
- 二重积分、三重积分
- 平面曲线积分
- 积分应用（面积、体积、弧长等）

### 4. 无穷级数
- 数项级数
- 幂级数
- 泰勒级数
- 傅里叶级数

### 5. 常微分方程
- 一阶微分方程
- 可降阶的高阶方程
- 常系数线性微分方程
- 微分方程应用

### 6. 线性代数（部分考纲）
- 行列式
- 矩阵
- 向量
- 线性方程组
- 特征值与特征向量

### 7. 概率与数理统计（部分考纲）
- 随机事件与概率
- 随机变量及其分布
- 随机变量的数字特征
- 参数估计与假设检验

## 学习建议

1. **先打基础**：极限 → 导数 → 积分，是高数的主线
2. **多做计算**：高数是"算"出来的，看懂不算会，能独立做题才算
3. **公式要背**：积分公式、导数公式、级数展开式，该记的必须记
4. **联系后续科目**：高数是工具，学物理力学时回来复习对应章节
