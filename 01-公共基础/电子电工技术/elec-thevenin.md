# 戴维南定理

## 核心定义

任何一个**线性有源二端网络**，对外电路来说，都可以用一个**电压源**和一个**电阻**的串联组合来等效代替：

- 电压源的电压等于该二端网络的**开路电压** $U_{oc}$
- 串联电阻等于该二端网络中所有独立源置零后的**等效电阻** $R_{eq}$

## 直觉解释

想象一个黑盒子，外面只露出两个端子。不管盒子里面有多复杂（几十个电阻、一堆电源），只要里面都是线性元件，从外面看，它就"像是"一个电池串一个电阻——给它接个负载，负载上的电压电流关系，和真实电池是一样的。

**为什么这很有用？** 因为当你只关心某一条支路上的电流/电压时，不用管其他部分有多复杂，把其余部分统统等效成一个戴维南电路，问题立刻变简单。

## 等效电路

```
        R_eq
   ────/\/\/\────
  │               │
  │    +          │  → 对外等效
  │  Uoc          │
  │    -          │
  │               │
   ───────────────
```

戴维南等效电路：电压源 $U_{oc}$ 串联电阻 $R_{eq}$。

## 戴维南定理解题步骤

### 第一步：求开路电压 $U_{oc}$

把待求支路断开，求开路端口的电压，就是 $U_{oc}$。

方法：用 KCL、KVL、节点电压法、叠加定理等任何你擅长的方法。

### 第二步：求等效电阻 $R_{eq}$

将有源二端网络中的所有**独立源**置零：
- 独立电压源 → 短路（电压为 0）
- 独立电流源 → 开路（电流为 0）

> **注意**：受控源要保留，不能置零！

然后求端口的等效电阻。方法：
1. **电阻串并联法**（不含受控源时）：直接化简
2. **外加电源法**：端口加电压 $U$，求流入电流 $I$，$R_{eq} = U/I$
3. **开路短路法**：$R_{eq} = U_{oc} / I_{sc}$（$I_{sc}$ 是端口短路电流）

### 第三步：接回待求支路，求解

把待求支路接回戴维南等效电路，用欧姆定律或简单电路分析求解。

## 适用条件

1. 二端网络必须是**线性**的（电阻、独立源、受控源、电容电感等线性元件）
2. 外电路可以是非线性的
3. 二端网络和外电路之间没有耦合（受控源不能跨接在内外之间）

## 典型应用场景

1. **求某一支路的电流/电压** — 最经典的应用
2. **最大功率传输问题** — 负载电阻等于戴维南电阻时，负载获得最大功率
3. **电路变化分析** — 只改一条支路时，其余部分不用重算
4. **含受控源电路** — 用外加电源法求等效电阻

## 最大功率传输定理（戴维南的重要推论）

当负载电阻 $R_L$ 等于戴维南等效电阻 $R_{eq}$ 时，负载获得最大功率：

$$
P_{\text{max}} = \frac{U_{oc}^2}{4R_{eq}}
$$

这个结论在通信、电子电路中非常重要。

## 戴维南 vs 诺顿

| 名称 | 等效形式 | 关系 |
|------|----------|------|
| 戴维南 | 电压源串联电阻 | $U_{oc} = R_{eq} \cdot I_{sc}$ |
| 诺顿 | 电流源并联电阻 | $I_{sc} = U_{oc} / R_{eq}$ |

两者可以通过电源等效变换互转。**有受控源时，诺顿等效和戴维南等效不一定同时存在。**

## 典型考点

1. **求戴维南等效电路**：给定电路，求 $U_{oc}$ 和 $R_{eq}$
2. **用戴维南求支路电流**：典型计算题
3. **最大功率传输**：求负载获得最大功率的条件和最大功率
4. **含受控源电路**：外加电源法求等效电阻
5. **概念判断题**：戴维南定理的适用条件

## 易错点

1. **受控源也置零了**：独立源置零，受控源必须保留！
2. **开路电压方向搞反**：$U_{oc}$ 的极性要和等效电压源极性对应
3. **求 $R_{eq}$ 时外电路没断开**：求等效电阻时，待求支路必须已经断开
4. **含受控源用串并联法**：有受控源时不能直接电阻串并联，要用外加电源法
5. **直接把原电路的电阻当 $R_{eq}$**：必须是独立源置零后的等效电阻，不是原样搬过来

## 典型题

**题**：电路如下图所示，求 $R_L = 4\,\Omega$ 时的电流 $I$。

```
      2Ω        4Ω
   +────/\/\/\───/\/\/\───+
   │           │          │
  12V          6Ω        RL
   │           │          │
   +───────────+──────────+
```

（12V电压源串联2Ω，中间节点接6Ω电阻到地，4Ω电阻后接RL到地）

**解**：
**第一步：求开路电压 $U_{oc}$**（断开 $R_L$）

断开后，4Ω电阻中无电流，开路端电压等于6Ω电阻两端电压。
2Ω和6Ω串联接12V：
$$
U_{oc} = 12 \times \frac{6}{2+6} = 12 \times \frac{6}{8} = 9\text{ V}
$$

**第二步：求等效电阻 $R_{eq}$**（电压源短路）

12V短路后，2Ω和6Ω并联，再和4Ω串联：
$$
R_{eq} = 4 + \frac{2 \times 6}{2 + 6} = 4 + \frac{12}{8} = 4 + 1.5 = 5.5\text{ Ω}
$$

**第三步：接回 $R_L$，求电流**

$$
I = \frac{U_{oc}}{R_{eq} + R_L} = \frac{9}{5.5 + 4} = \frac{9}{9.5} \approx 0.947\text{ A}
$$

**答案**：$\boxed{I \approx 0.95\ \text{A}}$
